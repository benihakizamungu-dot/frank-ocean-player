# 📁 Music Folder Structure

Upload your Frank Ocean MP3 files to these folders:

## Channel Orange

Place your Channel Orange tracks in the `/music/channel-orange/` folder:

```
music/
└── channel-orange/
    ├── 01-Thinkin-Bout-You.mp3
    ├── 02-Pink-White.mp3
    ├── 03-Novacane.mp3
    ├── 04-Super-Rich-Kids.mp3
    ├── 05-Pyramid.mp3
    └── 06-Sweet-Life.mp3
```

## Blonde

Place your Blonde tracks in the `/music/blonde/` folder:

```
music/
└── blonde/
    ├── 01-Nikes.mp3
    ├── 02-Ivy.mp3
    ├── 03-Pink-White.mp3
    ├── 04-Skyline-To.mp3
    ├── 05-Self-Control.mp3
    └── 06-Nights.mp3
```

## How to Upload

1. Create the folder structure above in your repository
2. Upload your MP3 files to the corresponding folders
3. The player will automatically find and play them
4. File names must match exactly (case-sensitive)

## File Naming Convention

- Use hyphens `-` instead of spaces
- Start with track number (01-, 02-, etc.)
- Use exact names from the player dropdowns

Example: `01-Thinkin-Bout-You.mp3`

---

Once uploaded, open `index.html` in your browser and the player will load all tracks!
